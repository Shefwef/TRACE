## Wide reference-slider observations

The reference uses a horizontal sequence of portrait cards with a calm white/light background, a large portrait treatment, concise person metadata, and enough card width for name and a short secondary line. For TRACE, the requested right-to-left moving rail should retain the existing institutional palette and avoid copying the reference's external social controls.

The reference continues this same repeated-card pattern across the full horizontal span. The TRACE implementation will use a continuous duplicated eight-person sequence, giving each card a portrait, name, designation, short bio excerpt, and direct route to the expanded Team profile.
