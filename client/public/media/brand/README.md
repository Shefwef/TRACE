# TRACE Full Wordmark Variants

Copy the supplied TRACE full-wordmark variants into this folder using these exact filenames:

```text
trace-consulting-wordmark-navy.webp
trace-consulting-wordmark-white-header-final.png
```

The header chooses the navy wordmark over paper backgrounds and the white wordmark over the cinematic hero. The footer uses the white wordmark. These local files are used whenever `VITE_USE_LOCAL_MEDIA=true` is set at build time.
